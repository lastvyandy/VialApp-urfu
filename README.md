# VialApp

VialApp is a web platform designed to help people in Chile prepare for the theoretical driving test for Class B and Class C driving licenses.

## Target User

People in Chile who are preparing for the theoretical driving test and want to practice online before taking the official exam.

## MVP Scope

The MVP includes:

- User registration and login
- One free practice test
- Class B and Class C courses
- Practice tests
- Test results
- 7, 15 and 30-day subscription plans
- Online payment through Webpay
- Basic user account information
